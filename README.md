==================================

OBJETIVO
---
Desarrollar una aplicación web para la gestión de productos de una tienda, utilizando PHP, MySQL, HTML, CSS, Bootstrap y JavaScript, que permita registrar, consultar, buscar, actualizar y eliminar productos de manera organizada y eficiente, garantizando la validación y el almacenamiento adecuado de la información en una base de datos.

Además, fortalecer las habilidades de trabajo colaborativo mediante el uso de Git y GitHub, permitiendo que los integrantes del equipo desarrollen, compartan e integren sus funcionalidades utilizando el control de versiones.

==================================

DESCRIPCION
---
Aplicación web para gestionar los productos de una tienda, que permite registrar, consultar, buscar, editar y eliminar productos. Cuenta con una base de datos MySQL para almacenar y organizar la información de cada producto, facilitando su administración mediante una interfaz sencilla e intuitiva.
